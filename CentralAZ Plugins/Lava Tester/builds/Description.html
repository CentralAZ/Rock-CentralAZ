The Lava Tester has support for Person, Group, Workflow, and RegistrationInstance / Registrations.

Added new features and is compatible with Rock v8.

Release Notes

  • v1.6.1 - 2/24/2025
    • Fixed compatibility with Rock v17 (Page model changes).
  • v1.6.0 - 8/23/2018
    • Added workflow Activity
    • Added ability to see inactive workflow instances and inactive activities.
    • Added date stamp in workflow instance and activity names to better find the one you're looking for.
    • Added using a HTML comment on the first line of the lava snippet as the slot name.
    • Added up to 25 save slots.
    • Added changing the editor height to take effect immediately.
  • v1.5.1 - 2/21/2017
    • Performance improvements to only render when you press the Test button.
    • Fixed some bugs with the Debug mode
    • Fixed some bugs added in last version
  • v1.5.0 - 6/5/2016
    • Added support for Registration Instances and Registrations.
    • Added a "save slots" feature to save and load your favorite lava snippets.
    • Allow changing the editor's height.
    • Added Merge Field injector for adding little lava bits to your lava.
    • Added link to Lava docs to make referencing documentation quicker
    • Fixed some bugginess
    • Added some bugs
